# Expense-tracker-ml
Expense Tracker with analytics and ML-based expense prediction using Flask &amp; scikit-learn

## Overview
A full-stack Expense Tracker web application that allows users to manage expenses, analyze spending patterns, and predict future expenses using Machine Learning.

## Features
- Add expenses
- Store expenses in database
- View expense history
- Category-wise spending summary
- Spending insights
- Predict future expenses using Linear Regression

## Tech Stack
- Python
- Flask
- SQLite
- HTML
- JavaScript
- Scikit-learn

## Machine Learning
Implemented Linear Regression to predict future expenses based on historical spending data.

## How to Run

1. Install dependencies

pip install flask scikit-learn numpy

2. Run

py app.py

3. Open

http://127.0.0.1:5000/
